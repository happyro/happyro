# 2026-09-26

## Added

- `[root]` 新增本机 Docker 运维工具 `tools/operations/manage.py`，支持按账号预览和清空角色；执行前停写并备份完整游戏库，保留账号及账号仓库，拒绝处理存在队伍、公会或家庭关系的角色。无参数仅显示帮助，支持规定的 ANSI 高亮及 `--no-color`。
- `[client]` 移动端新增素质菜单，支持按实际消耗逐点加点、查看服务器回传的相关数值及本次变化；四转职业显示基础素质与四转素质两个标签页，分别确认重置并返还对应点数。
- `[client]` 技能菜单新增重置技能点按钮，确认后按服务端规则重置可重置技能并返还点数；加点及重置期间阻止重复操作，并显示处理结果。

## Changed

- `[root]` macOS 原生应用启停脚本改用独立容器 `happyro-native-database`，避免误启完整 Docker 游戏栈数据库；补充独立数据、端口及 launchd 运维说明。
- `[client]` 缩小并居中显示素质加点「+1」按钮，保留原有行高、行距及数值位置，为按钮上下留出空隙。
- `[client]` 镜头控制移入设置的「镜头」分类，支持旋转、缩放、俯仰和重置，点击立即生效。

## Fixed

- `[server]` 修复容器重启或重建后 Map → Char、Char → Login 持续连接缓存旧 IP 的问题；每次重连重新解析服务名，启动或重连时 DNS 暂时失败会保留原配置并继续重试。
- `[client]` 技能栏上方按钮与提示区域的内部空隙不再穿透触摸触发移动，允许触摸判给相邻操作按钮，顶部状态框保持自身范围；保留第 1、2 个技能槽上方外侧空白的点地移动，手机和平板均适用。
- `[client]` 修复停止自动战斗或手动移动暂停追击时偶尔后退的问题，取消排队攻击后使用 `0xd03` 请求沿服务器当前路线停步，移除向客户端取整位置移动的旧停止方式。

## Performance

- `[client]` 移动端摇杆松手或触摸取消时立即发送一次停止请求；保持已确认的摇杆请求节奏、目标距离与行走动画，地面点击不发送停止请求。
- `[server]` 新增 `0xd03` 停止请求，沿服务器当前路线缩短剩余步程并同步本人和附近玩家，减少松手后的继续移动，不强制回退到格子中心。客户端与服务端须配套部署，保持 `PACKETVER=20211103`。
