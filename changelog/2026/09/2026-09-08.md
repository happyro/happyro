# 2026-09-08

## Changed

- `[client]` 技能树和技能详情使用覆盖全部职业的 1635 条简体中文技能名称与机制说明。
- `[client]` 魔物图鉴增加服务端常驻刷新地图列表和地图传送，并让冒险工具根据当前视口动态居中。
- `[client]` NPC 图鉴、地图导航和游戏内 NPC 名称统一使用完整中文词库及同一份地图坐标实例索引，玩家可见 NPC 不再回退到英文或韩文主名称。
- `[client]` 地图图鉴使用已核验图片清单将有图地图优先排列，无图片地图统一后置。
- `[client]` 修复冒险工具的地图默认落点、无图地形预览、同名刷新地图和持久状态提示等交互问题。
- `[client]` 地图图鉴将寻路限制在角色当前地图，显示角色位置、目标点与路径，并按需生成 GAT 地形缩略图；寻路状态会随到达、失败和中断正确结束。
- `[client]` 导航与 NPC 图鉴开始共享统一世界实体模型，统一地图坐标、能力标记和静态资料状态，避免两个入口对同一目标使用不同的数据形状。
- `[client/server]` 地图传送改用服务器权威的结构化请求与响应，导航和冒险工具统一等待真实结果后再更新冷却与提示。
- `[client]` NPC 图鉴改以服务器实例目录为完整来源并用官方导航增强身份，保留无导航记录的真实 NPC，同时仅向可实时校验的实例开放 NPC 传送。
- `[client]` 冒险工具增加角色维护和游戏设置标签页，使用当前游戏会话读取并维护本人角色、回读全服设置，且兼容 HTTP 环境的幂等提交。
- `[server]` Game Control 增加在线角色实时快照和即时保存，并提供默认“所有人”的角色维护、游戏设置开放范围。
- `[admin]` 游戏内游戏设置不再暴露权限治理字段，并按已认证游戏账号独立限流；后台继续独占治理开关。
- `[server]` Game Control 统一设置读取与应用的服务端边界定义。
- `[server]` 将 battle-config 处理从 Game Control Socket 入口抽出，保持主线程状态访问不变并降低入口复杂度。
- `[server/admin]` 修复 battle-config 响应格式异常导致后台游戏规则页面加载失败的问题。
- `[gateway]` 统一反向代理的逐跳请求头过滤、超时和断连处理。
- `[client]` 冒险工具按会话能力显示受控管理标签并抽取共享 HTML 转义工具。
- `[client]` 统一图鉴侧栏宽度、扩大操作按钮、缓存 NPC 目录，并将游戏设置和角色重置确认改为游戏内对话框。
- `[server]` 角色属性维护允许使用完整服务端整数范围，不再被普通属性上限 99 限制。
- `[server]` 将技能命中率计算提升为 32 位，修复高属性角色释放狂击、怒爆等技能时只有动画而没有伤害的问题。
- `[client/server]` 角色维护按实时派生加成限制基础属性，Alt+A 状态面板适配高位数显示，避免 32767 属性叠加后溢出。
