# 2026-09-07

## Added

- 客户端导航搜索支持单字关键词和 NPC 坐标区分；地图服务新增批量实时 NPC 校验，过滤未加载或对角色不可见的静态导航记录。
- `[client]` 地图导航新增全世界与当前地图搜索范围，以及由服务器确认实时目标和安全落点的 NPC 附近传送操作。
- `[server]` 新增 NPC 附近传送专用封包，复用导航权限、跨地图规则和冷却，并在服务端解析 NPC 与选择落点。
- `[client]` 右上角小地图可直接打开导航，导航支持地图搜索和可停止的角色自动寻路。
- `[client]` 导航传送入口使用服务器下发的权限、跨地图和冷却配置。
- `[server]` 新增服务器权威的网页地图传送策略、跨地图开关和冷却校验，默认向所有玩家开放，并支持运行时更新。
- `[client]` 左上角新增可扩展的冒险工具窗口，首个标签提供独立部署的完整魔物图鉴和权限感知的角色旁召唤交互。
- `[server]` 新增专用魔物召唤封包及服务器权威的权限、Boss/MVP、地图、冷却和自动清理规则，并复用 Game Control 的底层召唤实现。
- `[admin]`、`[server]` 新增服务器权威的地图分流开关，默认关闭并统一新手区域频道。

## Changed

- “传送服务”路线会在需要 NPC 对话时暂停并给出明确状态，完成传送后可继续规划。

## Fixed

- 修复 NPC 实时校验响应长度未注册导致网页地图 NPC 搜索无结果的问题。
- `[client]` 地图导航默认隐藏新手区域的频道副本；启用分流后显示可区分的频道编号和地图代码。
- `[client]` 放大导航窗口和地图可视区域，修正底部内容裁切，并以页内菜单和原生结果按钮避免导航选项覆盖游戏光标。
- `[client]` 魔物图鉴的普通掉落和 MVP 奖励使用 Renewal 物品资料中的中文名称。
- `[client]` 修复 Renewal 任务窗口的标签列表未正确显示和竖排文字重叠，新角色接取出生任务后可正常查看各个分类。
