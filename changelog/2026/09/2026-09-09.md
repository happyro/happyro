# 2026-09-09

## Changed

- `[docs]` 记录物品、NPC 和地图图像资源的离线生成产物及后台、游戏端加载边界。
- `[client]` 技能 ID、中文名称和说明改为构建时静态生成，运行时不再读取官方技能 ID 和说明 LUB。
- `[tooling]` 技能本地化生成器同步产出客户端静态目录，确保服务器技能定义与客户端展示可重复生成。
- `[tooling]` 物品资源生成器批量产出透明 PNG，供后台与游戏内物品图鉴共享。
- `[admin]` 冒险工具按查询、图片和写操作拆分限流额度，避免物品图鉴批量加载影响发放。
- `[client]` 物品图鉴使用离线生成的透明 PNG，并正确显示无纯色背景的详情图片。

## Added

- `[client]` 冒险工具增加可搜索的物品图鉴，并支持按后台权限设置向当前角色背包直接发放物品。
- `[server]` Game Control 增加具备校验、即时保存和重复执行保护的在线角色背包物品发放命令。
