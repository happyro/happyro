# 2026-09-09

## Changed

- `[client]` PWA 构建增加唯一构建标识、入口资源版本参数及失败状态传播；验收脚本会逐项校验本地和 3338 的关键产物哈希。
- `[docs]` 记录物品、NPC 和地图图像资源的离线生成产物及后台、游戏端加载边界。
- `[docs]` 记录技能与导航静态数据链、AI Lua 生命周期、改造前后资源体积和真实浏览器验收基准。
- `[client]` 技能 ID、中文名称和说明改为构建时静态生成，运行时不再读取官方技能 ID 和说明 LUB。
- `[tooling]` 技能本地化生成器同步产出客户端静态目录，确保服务器技能定义与客户端展示可重复生成。
- `[tooling]` 物品资源生成器批量产出透明 PNG，供后台与游戏内物品图鉴共享。
- `[admin]` 冒险工具按查询、图片和写操作拆分限流额度，避免物品图鉴批量加载影响发放。
- `[client]` 物品图鉴使用离线生成的透明 PNG，并正确显示无纯色背景的详情图片。
- `[client]` 技能窗口补齐 1279 条官方技能的逐项中文效果说明，并为官方说明表之外的 115 条旧宠物、内部及 NPC 技能补齐中文名称与可读说明。
- `[tooling]` 技能本地化生成器改为合并并校验官方说明、当前运行时技能和客户端静态技能全集，统一生成 1767 条名称、说明及客户端静态目录，阻止韩文和占位文案重新进入客户端。
- `[client]` 技能定义和职业技能树改用构建时静态模块，运行时不再执行 `skillinfolist`、`skilltreeview` 和 `jobinheritlist`。
- `[client]` 导航与冒险工具共享按需加载的 NavigationCatalog，并将仅寻路需要的连接及距离拆入 NavigationGraph。
- `[client]` 导航生成 JSON 固定使用 LF，保证跨平台生成一致性检查稳定。
- `[client]` 生命体与佣兵 AI Lua 改为按实体类型首次运行时延迟创建，普通角色启动只保留数据库 Lua 实例。
- `[client]` 隔离生命体和佣兵 AI 的重置生命周期，并阻止已取消的异步初始化重新发布失效 Lua 实例。
- `[tooling]` 增加带源文件哈希校验的技能运行数据与导航静态资源提取、生成工具。

## Added

- `[client]` 冒险工具增加可搜索的物品图鉴，并支持按后台权限设置向当前角色背包直接发放物品。
- `[server]` Game Control 增加具备校验、即时保存和重复执行保护的在线角色背包物品发放命令。

## Fixed

- `[client]` 清理 Alt+A 状态面板等纯文本提示中的颜色控制码，并修正物品发放确认层和缺失图片占位显示。
- `[admin]` 游戏内物品图鉴仅展示客户端与服务端共同支持的物品，排除缺少客户端资料的服务端内部条目。
