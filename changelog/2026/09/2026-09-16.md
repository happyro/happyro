# 2026-09-16

## Changed

- `[root]` 使用最新源码重新发布 v0.2.0 双架构镜像和统一离线包，并完成 Mac arm64 空库安装、游戏链路、后台接口及整栈重建验收；确认可选导入文件缺失和名称超长日志均已消除。
- `[root]` 离线部署模板补充 `SOCKET_PROXY_URL` 并传入 Gateway，支持将浏览器游戏 WebSocket 指向独立源站域名，同时保持默认同源行为。
- `[root]` Admin 镜像补齐 `php.ini`，把此前依赖 PHP 内置默认值的 `memory_limit` 显式设为 256M 并配置 OPcache；nginx 开启 gzip，覆盖 JSON 接口和前端静态资源。
- `[root]` NPC 目录不再生成客户端精简副本，地图目录和 NPC 实例名称表改为写入客户端 PWA 数据目录，供运行时按需获取。
- `[client]` NPC 图鉴和地图图鉴改为向 Admin 冒险工具接口按页取数，不再把 3.6 MB 的 NPC 目录打进主包；地图详情按地图单独取回该图全部 NPC 用于预览标记。
- `[client]` 魔物图鉴掉落资料拆分为按需加载的独立文件，导航用的 NPC 实例名称表和地图目录同样改为按需获取；主包 `Online.js` 从 20.06 MB 降到 14.24 MB。
- `[root]` 更新游戏资料、架构和运维文档，同步 NPC/地图查询改为服务端分页、魔物图鉴维持客户端全量加载的架构决策，并补充 Admin 数据流调用链；清理三个已废弃的空文档目录，新增一批部署缺陷记录，移除 Docker 发布文档中已过期的 v0.2.0 具体构建记录。
