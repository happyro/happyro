# v0.3.2

发布时间：2026-09-26 01:21:52 UTC。来源：[GitHub Release](https://github.com/happyro/happyro/releases/tag/v0.3.2)。

> 本页于 2026-10-12 归档 GitHub Release 当前正文，仅统一换行。以下下载信息、验收结论、`latest` 指向及已知限制为历史记录，不代表当前状态。

v0.3.2 主要完善手机／平板的素质加点与技能重置，优化触屏移动的停步响应，并修复自动战斗暂停追击时偶尔后退的问题。

## 移动与战斗

- 手机／平板松开移动操作或触摸取消时，立即向服务端发送停止请求，减少松手后的继续移动。
- 服务端沿角色当前路线缩短剩余步程，并同步本人和附近玩家，避免强制回到格子中心。
- 修复停止自动战斗或手动移动暂停追击时，角色偶尔后退的问题。
- 修复技能栏上方按钮与提示区域内部空隙穿透触摸、误触地面移动的问题，手机和平板均适用。

本次停步优化需要客户端与服务端配套更新，`PACKETVER` 保持 `20211103`。

## 手机与平板

- 新增素质菜单，支持按实际点数消耗逐点加点，并显示服务器回传的数值与本次变化。
- 四转职业分别展示基础素质与四转素质，支持分别确认重置并返还对应点数。
- 技能菜单新增重置技能点按钮，确认后按服务端规则重置可重置技能并返还点数。
- 加点与重置期间阻止重复操作，并显示处理结果。
- 优化素质加点「+1」按钮的尺寸与对齐，保留属性行的间距和数值布局。
- 镜头控制移入设置中的「镜头」分类，支持旋转、缩放、俯仰和重置，点击立即生效。
