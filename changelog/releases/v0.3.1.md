# v0.3.1

发布时间：2026-09-25 01:34:57 UTC。来源：[GitHub Release](https://github.com/happyro/happyro/releases/tag/v0.3.1)。

> 本页于 2026-10-12 归档 GitHub Release 当前正文，仅统一换行。以下下载信息、验收结论、`latest` 指向及已知限制为历史记录，不代表当前状态。

v0.3.1 主要改善 iOS 战斗音效与特效流畅度，优化手机／平板面板布局，并修复管理后台的地图显示与页面访问问题。

## 战斗流畅度与稳定性

- 短音效统一使用共享 Web Audio 播放与解码缓存，预热常用角色／武器音效，减少攻击时的音频卡顿，并完善音量、距离衰减和切后台恢复处理。
- 2D／3D 图片特效复用已加载的纹理，预热普通命中和暴击常用图片，减少重复攻击时的图片解码与纹理上传开销。
- 特效缓存设置容量限制，切图时清理；完善资源加载失败、释放和图形上下文丢失时的处理。
- 资源清理改为分帧执行并限制每帧耗时，减少集中清理造成的停顿。
- 修复角色动作切换时可能产生负动画帧索引的问题。
- 新增可选的移动端战斗诊断与日志回传，帮助定位音频、动画、特效和纹理处理中的卡顿；普通游戏入口不启用性能采样。

## 手机与平板

- 手机菜单、列表、表单与详情面板采用更紧凑的布局，减少横向留白；输入文字保持合适字号，避免 iOS 聚焦时自动放大。
- 平板横屏使用独立尺寸规则，放大人物状态、战斗控件、小地图与菜单弹窗，自动战斗和快捷槽配置充分利用可用空间。
- 设置按画面、特效、声音分组，固定保存区域并显示音量百分比；切换分组保留未保存的设置。
- 改善人物信息的层次、间距与数值对齐，统一菜单子页面的列表、详情、分类和状态提示。
- 优化快捷槽候选技能卡片与等级编辑布局，保存后直接显示成功或失败；自动战斗范围设置常驻显示。

## 管理后台

- 魔物详情补齐 349 个刷新地图的中文名称，以紧凑表格展示地图、常驻数量和位置操作。
- 修复 Docker 部署下直接打开或刷新魔物图鉴等页面时，错误跳转到容器内部 8080 端口的问题。

## 已知限制

- iPhone Chrome 已完成音效修复实机验收；共享特效纹理优化后的 iPhone 采样确认复用生效，但最终画面效果、长时间战斗及 iPad 实机仍需补充复测。
- Safari 通过 HTTP 访问时的 WebSocket 登录问题尚未确认修复；请使用 HTTPS，或暂用 Chrome 访问。
- 移动导航目前提供搜索与路线预览，尚未完成自动行走；自动战斗不支持全地图巡逻。
- 部分低频窗口、伴侣操作及真实消耗场景仍待完善或验收。
