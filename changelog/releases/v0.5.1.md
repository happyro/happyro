# v0.5.1

本版完善经典初心者流程、地图加载恢复、桌面冒险工具和后台账号管理，并统一部署默认值、时间显示及离线包资源清理。以下按当前生产功能与配置说明变化；安装文件、校验摘要和镜像交付信息以[资源下载](https://happyro.kugarocks.com/guide/downloads)为准。

## 经典初心者与修炼场

- 支持 `HAPPYRO_NEW_PLAYER_START=classic|ship`，默认 classic；新建人类角色出生和初始保存点为 `new_1-1,53,107`，杜兰流程独立。已有角色位置不迁移，角色登录及传送入场默认面向正南。
- 恢复经典教学、职业手册、任务和问卷；修复取消仍传送、更换手册卸掉普通装备、任务登记与清理、奖励容量检查及旧离场交通位置。
- 审校经典新手及九个一转职业的 NPC 名称、对白、材料和任务说明，修复转职后职业等级显示被外观重建覆盖的问题。
- 修炼场 20 张平行地图在关闭分流时按四个实际区域展示；补齐 NPC 导航关联，五个出生分流使用木制公告牌。
- 补齐训练地图、假人外观及对应目录资源；按官方映射识别共享场景，完善小地图与中文名称。

- 女武神转生对话补充受限初心者装备卸下后出售、携带及出售所得 Zeny 存入银行的说明，明确零负重和零携带 Zeny 等准备要求。

## 地图与资源

- 地图关键资源加载失败时尝试上次成功位置，再失败返回普隆德拉；30 秒加载超时提供重试和返城。隔离旧加载与迟到图片，安全点仍失败时停止循环。
- 修复声望图片异步加载产生 undefined 请求，桌面随机加载图限定为当前官方八张资源。
- 补齐宠物教学小波利共用的 2398 外观缩略图，以及另外 114 种 NPC 外观缩略图，后者覆盖 427 个 NPC 实例；同步 API 目录和客户端图集。这些是目录预览资源，不等同于全部场景模型、贴图和音效都已补齐。

- 修复女武神大厅等天空地图云层误用地面纹理、出现贴图漂移的问题。

## 桌面与移动端交互

- 桌面右下角提供自动战斗、自动拾取和设置常驻按钮，独立启停并显示状态；设置窗口集中维护参数。战斗与拾取开启时使用浅黄色，关闭时灰色且为 70% 不透明度。
- 桌面冒险工具通过亮色圆角弹窗输入物品数量与 Zeny。两者分别保留草稿，关闭冒险工具后重置为数量 1、Zeny 空值。
- Zeny 按钮使用「-100万」「-10万」「+10万」「+100万」；空值按 0 参与加减，空值或 0 不能发放，确认期间阻止重复提交。
- 手机竖屏快捷键筛选固定在列表底部；任务入口移至左上角并默认选中首项；状态在右侧分列显示原始图标，点击在图标旁显示桌面同款说明，不跳转弹窗。
- 手机和平板默认镜头拉近；自动战斗默认开启无目标随机瞬移，无目标等待和最短瞬移间隔均为 2 秒。
- 修复目标消失引起的空引用和封包回调异常导致的后续消息丢失，自动战斗可继续寻找目标。

- 状态图标共用桌面倒计时遮罩和彩色说明；手机竖屏按实际可用高度换列，横屏在角色信息右侧换行，说明显示在下方。统一小地图与操作区右侧间距，修正拾取提示避让。
- 任务和状态详情统一标题样式；状态详情显示剩余时间，列表按即将到期优先排序。
- 自动战斗攻击目标展示当前地图全部配置魔物，以两列排列，不依赖周围可见魔物。
- 冒险工具地图预览下方增加魔物表格，提供详情链接、等级、HP、属性与基础／职业经验；保留地图高度，各端无表内滚动条，缺失数值显示“-”。物品图鉴掉落表格各字段统一左对齐。

## 后台账号与设置

- 账号可设为游戏管理员 GM（99）或普通玩家（0），使用独立 `players.gm` 权限。设置作用于全账号，完整退出游戏并重新登录后生效，不改变后台管理员身份。
- GM 保存校验旧权限组、服务器账号与删除状态，并记录审计；管理库迁移为 administrator 添加对应权限。
- 用户账号通过带编辑图标的「操作」菜单管理，敏感操作分隔，批量入口显示选中数量。GM 弹窗显示账号摘要、身份选项和重登提示。
- 游戏角色保留直接打开「角色属性」的六个 Tab 弹窗，便于连续调整；按钮使用统一描边和编辑图标。
- 游戏设置页移除底部嵌入的历史列表，从页头、保存提示或独立菜单进入修改记录。

## 配置与维护

- 客户端默认设置由 schema 统一定义，Gateway 动态提供运行配置；已保存的个人设置优先。脚本文字最低对比度可配置，默认 4.5。
- 增加地图视野、行走上限、导航、召怪和工具权限环境变量；默认视野为 18。非空环境覆盖项不能在后台保存，冲突时整批拒绝。
- 数据库存储与 API 输出统一时间语义，API 使用带时区时间；显示时区通过 `APP_TIMEZONE` 配置，默认 Asia/Shanghai，不转换既有历史数据。
- `ADMIN_CSRF_ORIGIN_CHECK_ENABLED` 默认 false，关闭后台 Origin 与 Sec-Fetch-Site 来源限制，仍强制校验会话 CSRF Token；设为 true 后实际来源必须匹配 APP_URL。
- 离线资源复制、清单和最终 ZIP 过滤任意层级的 `._*` 与 `.DS_Store`，保留业务文件和原始资源；历史包不回写。
