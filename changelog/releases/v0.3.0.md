# v0.3.0

发布时间：2026-09-24 08:00:35 UTC。来源：[GitHub Release](https://github.com/happyro/happyro/releases/tag/v0.3.0)。

> 本页于 2026-10-12 归档 GitHub Release 当前正文，仅统一换行。以下下载信息、验收结论、`latest` 指向及已知限制为历史记录，不代表当前状态。

v0.3.0 主要带来手机／平板触屏界面、自动战斗，以及四转技能与游戏稳定性改进。

## 手机与平板

- 新增移动端登录、创建角色、选角和横屏游戏界面，优化系统安全区、软键盘与 PWA 桌面启动体验。
- 支持左侧拖动移动、六格分页快捷栏、技能等级配置；点击 NPC 直接交谈，点击地面物品直接拾取。
- 指向性技能先选技能再点目标，自动靠近并根据目标移动重新检查射程。
- 自动战斗支持魔物种类多选、技能随机释放、搜索与活动范围配置；移动时暂停，停止移动后继续。
- 自动战斗配置按服务器、账号和角色保存在本机，下次进入恢复设置，不自动开启战斗。
- 接入背包、装备、技能、NPC 商店、仓库、任务、社交、强化、交易、摊位、银行、邮件及宠物等移动面板。

## 四转与游戏体验

- 补充四转导师、职业目录、特性操作及技能运行定义，完善多类技能动画、地面效果和召唤单位表现。
- 改进角色属性维护、职业切换和特性设置，补充技能失败的中文原因提示。
- 修复高属性下部分战斗、技能倍率与回复计算溢出。
- 修复部分副本名称引用、任务 ID、任务资料缺失及中文显示问题。
- 修复角色预览头饰重影、返回选角后外观消失，以及连接切换时的错误提示。

## 已知限制

- Safari 通过 HTTP 访问时存在 WebSocket 登录问题，待修复；请使用 HTTPS，或暂用 Chrome 访问。
- 移动导航目前提供搜索与路线预览，尚未完成自动行走；自动战斗不支持全地图巡逻。
- 部分低频窗口、伴侣操作及手机实机／真实消耗场景仍待完善或验收。
