roBrowser 是一个基于仙境传说 Online 的开源项目。
本项目与 Gravity 没有任何关联。 in any way with Gravity.

本项目旨在使用网页技术（HTML5、JavaScript、WebGL）复现游戏，并将其带到网页浏览器中。 it to Web Browsers.

跨平台：可运行于 Windows、Linux、macOS 以及任何支持 WebGL 的设备。
