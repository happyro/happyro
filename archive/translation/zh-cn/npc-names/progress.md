# NPC 名称翻译总进度

本文件是城镇和非城镇批次的唯一进度来源。范围、规则和验收标准见 [strategy.md](strategy.md)，单批次证据见 [batches/](batches/)。

## 状态标准

| 状态 | 定义 |
| --- | --- |
| 未规划 | 尚未建立目标区域的活动地图范围和全量名称清单。 |
| 已排期 | 地图范围与优先级已确定，但尚未生成活动 NPC 全量清单。 |
| 清单完成 | 已生成人工复核后的全量清单，客户端译名尚未全部补齐。 |
| 翻译中 | 已实现部分显式译名，但自动覆盖检查仍有缺失。 |
| 部分覆盖 | 已翻译部分核心或公共 NPC，但没有证明全地图英文基础名称缺失数为 0。 |
| 待实机验收 | 全量映射、截断检查、测试和构建已通过，但尚未完成目标地图的实机抽查。 |
| 已实现 | 范围、全量清单、客户端映射、封包截断、构建和实机验收全部通过。 |

连续批次共用同一名称显示链路时，可按用户要求合并做少量代表性实机取样；逐批次完整性仍由活动清单和自动覆盖检查证明。

“已实现”适用于一个明确的批次范围，不能根据少量核心 NPC、单个服务端脚本文件或服务端构建通过来判定。

## 全局活动脚本审计（2026-08-27）

- 从 `npc/re/scripts_main.conf` 递归展开 836 个当前活动脚本文件。
- 提取到 11048 个具有地图实例、非隐藏精灵和 ASCII 基础名的活动定义。
- 与客户端运行时名称表及 23 字符封包截断别名比对后，剩余 2560 个待审阅候选。
- 其中 603 项能关联到唯一的已翻译对话标题，只作为译名候选；其余 1957 项等待人工可见性与译名复核。
- 审计按基础名保留全部实例地图，并递归关联 `duplicate(Source)` 的无地图或跨文件模板，避免共享模板因首个实例位于其它地图而漏扫。
- 出生流程、伊兹鲁德、拉萨格纳及其分流实例已按上述新口径复核，当前缺失数为 0。
- 完整审计快照位于 [`batches/inventories/p4-active-candidates-20260827.csv`](batches/inventories/p4-active-candidates-20260827.csv)；它不直接作为翻译源，每个正式批次仍须人工分类并将确认译名写入客户端显式表。

## 统计口径

- 旧估算声明数包含重复实例、隐藏脚本和非玩家可见项，只保留为历史工作量参考，不能作为完成数量。
- 全量检查从服务端当前活动脚本的 NPC 定义中提取第三个制表符字段，再去除 `#...` 实例后缀和 `::...` 事件别名，以英文基础名称去重。
- 每个批次必须先明确地图范围和排除项；城镇、野外、迷宫和地下城不得跨批次重复统计。
- `glossary/npc-name-terms.csv` 是跨地图复用的术语表，不是全量完成清单；不能用术语表条目数证明批次已经完成。
- 客户端运行时名称表是悬停名称和名称牌译文的维护源。服务端脚本仍是名称清单和对话标题的来源，但不得为了悬停显示而批量修改可能被脚本引用的 NPC 内部标识。
