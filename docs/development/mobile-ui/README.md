# 移动端游戏 UI 重构

本目录记录 HappyRO 移动端游戏界面的重构方案与实施进度。已完成首轮组件与输入入口盘点，尚未修改游戏 UI 产品代码。已完成的登录、选角、创建角色适配是前置成果，不代表游戏内窗口已适配。

- [整体方案](plan.md)：已确认约束、首屏布局、交互规则、代码边界和验收要求。
- [入口与输入盘点](inventory.md)：首屏组件、旧摇杆与手柄区别、事件冲突、复用边界和下一阶段接入点。
- [实施进度](progress.md)：分阶段任务、完成证据与待确认事项；每批实现和验收后更新。

方案中区分已确认需求和待细化建议；未经实现和验证的内容不计为完成。
