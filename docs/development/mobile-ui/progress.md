## 2026-09-23：摇杆及技能扩展方案确认

- 原生 Pointer Events 实现新屏幕摇杆和按钮输入；按控件独立跟踪触点并处理捕获与取消，暂不引入第三方摇杆库。
- 审查后复用方向转换、可行走格检查及共享业务；不沿用旧 MobileUI 的触摸事件代码，保留 JoystickUI 实体手柄。
- 横屏首屏预留右下大攻击按钮、周边可配置小技能槽位；左手移动与右手攻击／技能输入互不取消。
- 明确自身、指定目标、地面范围和可选等级技能的交互；地面选点需要取消入口，并与普通地图移动互斥。
- 槽位通过点击选择技能与等级，展示图标、冷却和可用状态；具体数量与排列仍待细化。
- 本次只更新设计决策，阶段 1、2、4 的产品实现和测试仍未开始。
