# 说明标签处理

说明统一通过 `Utils/RagnarokText.js` 渲染。覆盖冒险工具、物品详情、装备比较、任务、NPC、技能、成就，以及移动端仓库、商店、交易、摆摊、材料、附魔、精炼和选择窗口。聊天中的玩家物品封包链接保留独立解析，不把玩家输入当作说明 HTML。

## 处理规则

- NAVI：沿用已审查清单；有坐标可传送或有魔物结果才可点击。普通说明跳转后关闭地图恢复来源；执行导航／传送后释放来源。NPC 原对话导航流程不变。
- ITEM / ITEMLINK：数字 ID 且当前物品表有名称才可点；在共用参考阅读器查看说明，支持返回历史页面。缺失数据保留标签文字。技能 `^nItemID^数字` 同样解析为物品引用。
- TIPBOX：保留原帮助阅读器、分页和历史；内部 ITEM 可以查看物品，内部 NAVI 可以打开地图／魔物资料。恢复时保留页码和滚动位置，图片加载不会丢失原阅读位置。
- URL：只接受 HTTP/HTTPS 地址，移除末尾原端游窗口宽高元数据，在浏览器新标签页打开，不关闭当前来源窗口；非法地址仅保留文字。使用 noopener/noreferrer，游戏和 NPC 不接收同一次激活事件。
- FONT：支持无 `#` 的六位颜色、标准颜色属性和受限字号；旧像素字号转为相对字号并限制范围，适应手机和平板。其余 HTML 只开放文本排版标签，不保留任意属性、脚本或事件。
- INFO：作为链接元数据使用，不直接显示；残缺链接去除已知标签和内部数据，保留可读文案。
- `<Enter>`、`<Zzz>` 和命令占位符属于普通文字，保留显示。

交易、商店、附魔、精炼、材料和选择等服务端操作窗口的 NAVI 仅保留文字，来源 `data-navigation-blocked` 限制会继承到帮助及物品参考，不能借二次跳转绕过操作流程。普通背包、仓库、手推车、技能和快捷键支持来源挂起与恢复。
