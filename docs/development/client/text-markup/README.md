# 说明标签专题

[返回客户端专题](../README.md)

本目录集中记录 NPC、任务、物品、技能、成就和冒险工具中的说明标签。以最终交互与源码为准，历史审查快照不代表当前可点击范围，也不代表最终版本实机验收完成。

| 标签 | 当前功能 | 不可用时 |
| --- | --- | --- |
| NAVI | 坐标打开冒险工具地图；魔物打开图鉴；NPC 先加入导航，正常结束对话后提供独立入口 | 保留可读文字 |
| TIPBOX | 共用参考阅读器，支持分页、图片、历史返回 | 保留可读文字 |
| ITEM / ITEMLINK / ^nItemID^ | 当前物品表有名称的物品打开只读参考页 | 保留文字，不提供空链接 |
| URL | 安全 HTTP(S) 链接在浏览器新标签页打开 | 保留文字 |
| FONT | 受限颜色与相对字号，适配手机、平板和桌面 | 不保留任意属性或脚本 |
| B / I 等排版标签 | 白名单文本排版 | 非排版尖括号文字保留 |
| INFO | 引用内部目标数据 | 不独立显示 |

## 数量与验收口径

规范化翻译与全部 NPC 源码中共扫描 NAVI 7,015、TIPBOX 4,176、ITEM 1,777、URL 112、FONT 207、B 59、I 1 处。INFO 13,082 处是内部数据，不能重复算功能数量。扫描保留任务版本和 NPC 源位置，不能换算成已加载 NPC 数量。
