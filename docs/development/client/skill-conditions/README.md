## 已修复的确定问题

- 武器和防具类型写反：改用类型与实际装备槽常量，双持检查任一手；双手矛不再被判为空手，也不会被误判成盾牌。装备／背包中同一弹药按索引去重。
- 面板只计算一次：每 200 毫秒更新现有技能卡片文字，保留勾选、焦点和滚动，关闭时清理任务。
- 骑乘、姿态和球数：骑龙满足普通骑乘要求；日月星和宇宙姿态按服务端核对；独立接收灵魂球，修正已确认的气弹／仆从球豁免、部分球施放及 BladeStop 下阿修罗减一球。
- 材料和费用：零消耗工具仍必须持有；金钱攻击与手推车终结技在学习对应被动后减少 20% Zeny；Research Report 只减少酸化区域第一项材料；四个 Renewal 技能额外需要一发弹药；Hovering 元数据要求实际装备设备。
- 巅峰模式：Crystal Impact 的 1 级和 Destructive Hurricane 的 4 级才转为增益，原先统一拦截 2 级错误；All Bloom、Violent Quake 在 4 级作为地面减益，保留可用并使用既有减益频率预算。
- 特殊前置：Psychic Stream 在能量外套期间不可用；狼突击需要随行狼或骑狼。
- 魔物条件：Head Crush 使用真实 Boss class，不能把 Guardian 与 Boss 混同；毒爆、偷窃、偷钱、卸除对已知状态免疫对象不再尝试。未把所有减益一概排除 Boss。
