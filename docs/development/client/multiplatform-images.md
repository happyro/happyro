# 三端游戏展示图

用于 README、文档和发布说明中的 PC／平板／手机展示图。采用真实游戏截图与设备框合成，不使用 AI 重绘屏幕内容。本页记录首版预览的制作规则，后续收到新截图后按此重新合成；预览不等于已确认的正式发布素材。

## 截图输入

- 用户提供 PC、平板、手机各一张原始截图；PC 与平板横屏，手机竖屏。
- 截图只需游戏画面，不自行添加设备框、透视、阴影或宣传文字，不拉伸、不二次压缩。
- 优先采用同一版本、同一场景的截图，便于展示三端实际界面差异。也可以展示不同功能，但要保持视觉协调。
- 保留真实状态栏、小地图、聊天及操作区域；不要为了构图伪造、移动或重绘游戏 UI。
- 截图前关闭无关弹窗、输入键盘和临时提示，鼠标移出主要画面，避免私人聊天、账号信息等出现在宣传图。
- 优先使用适合公开展示的角色名。测试角色截图仅用于预览，正式发布前确认是否替换。
- 原图分辨率尽量不低于最终屏幕展示区域。宽高比不同于首版时，调整设备框比例，不能将截图硬拉到固定尺寸。
- 无截图时可从当前版本补拍，使用对应的桌面／触屏布局。浏览器模拟截图不能表述为物理设备兼容性验收。

首版截图尺寸仅供参考，不是用户提供截图的强制要求：

| --- | --- | --- |
| PC | 1440 × 900 | 横屏 |
| 平板 | 1180 × 820 | 横屏 |
| 手机 | 430 × 932 | 竖屏 |

## 画面与设备布局

- 主图为 2400 × 1680 横版 PNG，采用浅灰白背景、轻微渐变及柔和阴影。
- 上方居中写「HappyRO」，下方为「PC  /  平板  /  手机」。默认不写版本号，方便复用。
- PC 显示器居后且最大，横屏平板位于左前方，竖屏手机位于右前方。
- 设备使用正视角中性外框：显示器带银灰色支架，平板与手机使用深色窄边框，不附加硬件品牌标志。
- 平板和手机可遮挡显示器下部，但不要挡住 PC 的主要角色、关键内容或上方导航。
- 三块屏幕分别放入对应端真实截图，保持原始宽高比；圆角遮罩只处理屏幕边角。
- 不添加未确认的宣传口号、发布日期、二维码或平台兼容性承诺。

## 合成与输出

1. 检查三张截图的版本、方向、清晰度和公开展示内容。
2. 使用 Pillow 或等效工具绘制背景、设备框与阴影；按比例缩放截图并放入屏幕区域。首版使用 Pillow、Lanczos 缩放和 Noto Sans CJK 字体。
3. 标题采用深灰绿色，首版字号 88px、加粗；副标题采用灰绿色，字号 34px。阴影柔和，避免高光遮挡 UI。
4. 输出完整 PNG，同时生成 1440 × 1008 JPEG 预览；首版 JPEG 质量为 92。
5. 检查文字、设备比例、屏幕边缘、遮挡关系，以及缩小后能否区分三端界面。
6. 先交付预览，用户确认后再放入正式文档。生成新版本文件，不直接覆盖已确认素材。

建议文件位置：

- 输入截图、合成脚本与中间文件：`work/multiplatform-images/<批次>/`。
- 输出：`artifacts/multiplatform-preview/happyro-three-platforms-vN.png`。
- 预览：`artifacts/multiplatform-preview/happyro-three-platforms-vN-preview.jpg`。

`work/` 与 `artifacts/` 中的文件不随 Git 分发。本页规则是后续重建依据，不依赖首版临时脚本仍存在。首版输出名为 `happyro-three-platforms-v1.png` 和 `happyro-three-platforms-v1-preview.jpg`，仅作为本机预览。

确认使用后，根 README 的正式图片放入 `docs/assets/readme/`；文档站需要的正式图片放入 `repos/happyro-doc/docs/public/images/game/`，按实际引用更新文档。仅保留实际使用的素材，不把所有中间版本加入仓库。
