# 修复问题

## 出生模式与旧迁移 NPC 冲突

原 Renewal 只启用学院流程，经典地图中的迁移 NPC 与经典教官位置重叠，并会删除 7117～7127 任务、强制送回沉船。现在将沉船和经典教学作为两套当前流程同时启用，删除这些迁移 NPC 以及经典脚本中针对历史进度的兼容段。角色服启动时严格读取 `HAPPYRO_NEW_PLAYER_START`，以同一地点初始化出生与复活点；切换不改写已有角色。

主要文件：`repos/happyro-server/src/char/new_player_start.hpp`、`src/char/char.cpp`、`npc/re/scripts_jobs.conf`、`npc/re/jobs/novice/academy.txt`、`npc/re/jobs/novice/novice.txt`。Docker Compose、本机 profile 和 systemd 模板同步传入环境变量。

## 训练等级菜单取消仍执行传送

五个训练等级之后第六项是取消，原脚本判断选择值小于 7，会拼出不存在的 `new_6-3`。修改为仅 1～5 执行传送，并在正常传送前关闭对话；取消只结束对话。实机已验证取消及全部五档切换。

## 更换职业手册卸掉全部装备

原 `F_NvErase` 使用 `nude`，换手册时连新手衣服、鞋子和武器一起脱下。现在只检查左右饰品栏中实际装备的职业手册，再移除旧手册，保留普通装备。重登后在装备窗口中核对前后六件新手装备一致，随后正常转职成功。

## 教学、职业测验和任务显示的中文问题

补译经典 NPC 源名称、对白标题、30 题测验的英文选项和动态职业名；修正艾尔贝塔误称艾尔帕兰、小鸡误称波奇、树精名称与部分过时职业介绍。高级职业测验将一转入口职业正确显示为魔法师。

两份版本化任务翻译源统一斯普拉基／珍河等人名及任务目标，编译后语义校验并记录运行目标哈希。客户端共用任务进度和完成提示改为中文，任务按钮的辅助文字也一并翻译。实际击杀后已确认中文完成提示。

资源核验使用原始 `resnametable.txt` 映射；没有为旧格式添加别名、回退路径或历史数据迁移。详情及验证边界见 [verification.md](verification.md)。
