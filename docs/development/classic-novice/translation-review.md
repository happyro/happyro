| 职业介绍夸大或含糊 | 调整仓库容量、商人武器／技能、职业成长和离场说明，避免承诺代码不存在的功能 |

## 对照依据

以当前实际脚本的条件、物品数量、奖励和传送为行为依据，术语对照客户端职业／技能表及 API 中文物品目录。英文对照来自 [rAthena NPC 源代码](https://github.com/rathena/rathena/tree/master/npc)，本轮读取日期与逐文件 SHA-256 已记录在证据中。

问卷部分上游英文自身存在不通顺、含糊和转写残片；这部分按角色性格与上下文进行中文编辑，不宣称是经过官方确认的逐字翻译。人物名称保持项目现有译名体系，不另造多套译名。

NPC 目录重新生成并通过一致性检查，API 导入 generation 7；客户端完整 `--all` 构建为 `mvklmwpf`。地图服重新加载成功，本次新增日志无脚本错误或警告。
