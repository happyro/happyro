## 问卷全分支

逐项抽取并核对 30 道题的 **73 个答案分支**：每题选项索引与 case 完整对应；字符串代词分支赋值完整；积分只写入九种有效职业变量。九种职业均找到实际答案序列能使其成为推荐结果。对 **511 种非空并列最高分组合**验证选择算法，当前规则是索引较大的职业获胜。

共有 43,486,543,872 种完整答案组合，没有逐一模拟这些组合。代码审查覆盖全部单题分支与最终取最大值逻辑；九职业可达性用确定随机种子的答案见证验证，不把它当作全组合穷举。

第五题选“发生”会给盗贼累计 2 分，其他受影响职业加 1 分。这是现有代码的加权行为，没有足够依据认定为错误，因此保留并显式记录。问卷不是知识考试，没有必须统一成一分的“标准正确答案”。

推荐结果说明九个 case、接受推荐／选其他职业、两次确认取消及最后“我再想想”均已审查。取消时不调用离场清理。取消对白原本声称会发书但没有发物品，改为说明可向导师领取体验手册。
