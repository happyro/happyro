# 四转待办与边界

基础转职、职业目录、等级与特性/AP 操作、技能学习、常用形态及主要角色状态保存已有实现。后续先处理实际缺陷，不把全部视觉复刻视为基础功能交付门槛。

- 数据损坏、点数复制、无法登录、转职或等级请求部分生效：按最高优先级复现并修复。
- 常用技能文案和玩法反馈：对照当前源码与服务端结果复查；完整官方转职剧情、高等级地图、任务和装备获取渠道分别定义需求，不沿用旧 R5 排期作为执行指令。
- 治疗、召唤、陷阱/演奏、特殊形态、并发和死亡/切图/重登：共享机制已有抽样不代表全部成员逐项通过，按变化与反馈补充回归。
- 三个旧 `kunaiarea_00_{start,loop,end}` STR 记录为未引用缺口。只有出现实际引用或明确复刻目标时再追查来源。
- 全染色、全武器、全方向和逐帧官方复刻不属于已完成范围；引用资源安装、解析、绘制和玩法结果分别验证。

验收规则见[回归标准](acceptance.md)，最终发行包使用[发布清单](../../operations/release-checklist.md)。不以旧主机启动状态、构建号或测试数量证明当前通过。
