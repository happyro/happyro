# 四转后续路线

更新日期：2026-09-20。本页是未完成事项、收益排序和进入下一轮条件的唯一来源。基础四转 F01—F08 已交付，状态见[实现进度](progress.md)；本页不把视觉精修或全量测试重新设为基础交付门槛。

## 排序规则

正常迭代按“玩家影响 × 覆盖人数 × 发生概率 ÷ 实现与验证成本”排序，同时保留风险优先权：

1. 已确认会损坏角色数据、造成点数复制、无法登录，或让转职／等级主流程失效的问题，立即进入 P0，不等待当前工作包完成。
2. 同一优先级先处理阻断操作的问题，再处理数值／状态错误，最后处理纯显示差异。
3. 共享机制只验证代表样本；相同代码路径不按 20 个职业或全部技能重复测试。
4. 没有实际引用、没有复现或不影响操作的资源缺口不得挤占常用玩法工作。
5. 每次只启动一个主工作包；用户实际反馈可插入，但必须记录影响范围和复测证据。

## 当前依据

- 主流程、20 个职业目录、Base 275／Job 60、特性、保存重登和 PWA 运行入口已经完成，不再重复建设。
- 296 个技能树名称已与现有 STR／BSON 审计；当前 103 个技能树技能有显式映射，计入伤害子 ID 共 113 个，另有 22 个静态地面单位和 5 个 BSON 地面单位。继续盲目增加映射的边际收益低于真实战斗闭环。

- 3 条旧苦无 STR 缺口没有当前技能或地面引用，保持 R6；除非引用关系变化，不继续遍历补丁查找。
