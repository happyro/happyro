# 基础四转使用说明

## 游戏内转职

前往普隆德拉 `prontera` 的 **153,193**，与“四转职业导师”对话；也可在冒险工具 NPC 图鉴中查找该名称。

- 常规职业先成为对应的进阶三转，达到 Base 200／Job 70。
- 扩展职业使用对应前置职业，通常为 Base 200／Job 70；召唤师为 Base 200／Job 60。
- 先分配完剩余技能点；宝宝职业不适用此入口。
- 确认后保留 Base，Job 从 1 开始，开启四转特性及 AP。职业不符或条件不足时 NPC 会给出说明。

## 冒险工具

打开冒险工具（`Alt+F`），进入角色维护页，在职业列表搜索／选择四转职业。列表按当前角色性别提供可选项。

- 切换职业时可一并指定合法目标 Base，例如直接切四转并设为 250。
- 四转当前上限为 Base 275／Job 60，以服务端返回值为准；原三转保持自身上限，因此未转四转时仍不能直接突破其上限。
- 六项特性可按预算修改或独立重置；基础属性洗点不会顺带清空特性。
- 高等级四转切回低上限职业时，需要明确填写合法目标等级，系统不静默截断。
- 技能仍需满足前置和早期职业已分配点数要求。洗掉所有技能后，不能只靠增加剩余技能点直接学习最高阶技能。

本轮提供可用的四转主流程，不承诺所有特效、特殊形态和装备动作完整复刻。已知后续事项见[后续清单](backlog.md)。
