# 实现进度

最后更新：2026-09-20。

## 当前交付目标

按用户最新要求，先交付“大致可用的四转功能”，以主流程为重。同类型行为抽样验证；特效精修、少见技能差异、特殊装备动画和更多边界检查记录到后续，不阻挡基础功能交付。仍支持全部 20 个目标职业，不缩减职业范围。

**本轮基础四转功能已完成并在本机运行。** 这不等于所有技能和外观细节达到完整复刻。基础交付及追加的布局、跨职业动画修复均已按用户要求提交并推送到对应仓库的 `main`；未发布 Docker 镜像。

## 当前优先路线

基础交付后不再按“缺多少动画／测多少职业”推进。当前没有 R0 核心故障，**R1 常用技能真实战斗闭环、R2 角色状态生命周期和 R3 常用职业形态与召唤操作均已完成，下一主路线为 R4 高频技能视觉语义**。内容与无引用资源继续后置。

具体顺序、收益依据、完成标准和插队规则只在[后续路线](backlog.md)维护。本页只记录当前所在位置及已经完成的证据。
