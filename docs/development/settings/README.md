## 验收范围

本机 macOS Chromium 运行真实客户端和本机服务端；手机／平板以触摸浏览器环境模拟，覆盖横屏及菜单表单的真实事件处理，不冒认真机 iOS 验收。图形参数除存储检查外核对实际 GPU uniform、渲染视口与实体绘制；音频核对实际音频元素和输出增益，不声称人工听音。

## 修复与暂时关闭项

- 汉化设置光标、背景音乐等提示，统一渲染比例、像素清晰显示名称。
- 修复恢复默认后画布比例和光标未恢复的问题。
- 修复锐化／饱和度0值被默认值覆盖的问题。
- 修复像素过滤变更删除正在使用的纹理，以及调色板人物仍强制平滑的问题。刷新后全部精灵按选择加载。
- 统一饱和度步长0.05、抗锯齿边缘阈值步长0.001，确保默认0.15／0.125能被准确表示。
- 抗锯齿亚像素参数没有参与原着色器计算，入口暂时注释。恢复条件：实现算法并验证不同值确实改变渲染输出；保留现有有效抗锯齿开关和边缘阈值。
- 首批14项测试通过；最终涉及设置、着色器、精灵及附带修复的7文件26项测试通过。最终构建和像素采样回归通过；默认数值控件有效，两端验后恢复默认并重新登录。
