# 菜单设置审查

[返回开发文档](../README.md)

本次范围是 **菜单 → 设置** 的「画面、特效、声音」，按用户说明不包含战斗／拾取辅助设置。范围确认前已做的附带修复单列于文末，不计入菜单设置范围。

## 当前状态

本轮菜单设置审查已完成；发现的可用设置缺陷已修复，未实现的抗锯齿亚像素参数已隐藏，算法本身仍未实现。没有整项删除的设置。

验收基线为全量 PWA 构建 `mvdxkjl3`，当时 Gateway 的12个产物哈希核对一致。对应客户端提交为 `b5d78339`、`357f922a`；构建号是本轮验收记录，不代表后续环境一直运行该版本。

## 已修复

| 设置／入口 | 原问题 | 处理结果 |
| --- | --- | --- |
| 设置文案 | 游戏光标、背景音乐等提示残留英文或名称不清楚 | 汉化相关提示，统一“渲染比例”“像素清晰显示”等名称 |
| 恢复默认 | 偏好值恢复，但实际画布比例和光标仍保持修改后的状态 | 同步恢复渲染比例、画布大小及光标 |
| 自适应锐化：锐度 | 设为0，实际被默认值1覆盖 | 0能正确传入GPU |
| 自然饱和度：强度 | 设为0，实际被默认值0.15覆盖 | 0能正确传入GPU |
| 像素清晰显示 | 开启时删除正在使用的精灵纹理；调色板人物仍强制平滑 | 不再删除活跃纹理；调色板精灵支持最近邻采样，提示刷新以使全部资源按选择加载 |
| 自然饱和度：输入步长 | 默认0.15不符合原0.1步长，控件可能取整或报无效 | 步长改为0.05，可准确表示默认值 |
| 桌面抗锯齿：边缘阈值 | 默认0.125不符合原0.03步长，滑块显示值与实际值不一致 | 与菜单设置统一为0.001步长 |

## 验收范围

本机 macOS Chromium 运行真实客户端和本机服务端；手机／平板以触摸浏览器环境模拟，覆盖横屏及菜单表单的真实事件处理，不冒认真机 iOS 验收。图形参数除存储检查外核对实际 GPU uniform、渲染视口与实体绘制；音频核对实际音频元素和输出增益，不声称人工听音。

| 分类 | 设置 | 结果与证据 |
| --- | --- | --- |
