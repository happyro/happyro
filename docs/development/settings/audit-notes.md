# 设置汉化与功能审查

[返回开发文档](../README.md)

目标（按用户明确范围）：汉化“菜单 → 设置”中的提示，并在实际运行游戏中逐项验证画面、特效、声音三个分类。战斗／拾取辅助设置不属于本次验收范围。低成本缺陷直接修复；尚未实现且需要较大改动的设置先注释入口，记录恢复条件。不能以偏好值保存成功代替功能生效。

## 当前状态

进行中，先保存首批修复。首批全量 PWA 构建为 `mvdwfj5t`；当前已更新为 `mvdwp9mk`，Gateway 提供的 12 个产物哈希已核对，桌面测试角色已通过新版正常登录。14 项针对性自动化测试通过；修复后的逐项游戏内回归及其余设置审查尚未完成。本机 macOS Chrome 实际游戏验收与手机／平板浏览器模拟分别记录，不冒认真机 iOS 验收。

## 后续实测记录

- 桌面声音：界面音量设为25%，实际音乐元素音量与音效输出增益均为0.25；关闭后音乐暂停、音效增益为0，重新启用恢复播放。关闭重开面板保留选项，测试后恢复原50%音量；见 `audio-desktop.json`。这是音频播放链路验证，不声称人工听音验收。
- 桌面全屏：当前 Chromium 可进入全屏并退出（使用现有 WebKit 分支），见 `fullscreen-before.json`。源码补上标准 `document.exitFullscreen` 优先调用，标准API分支待回归；不将本次Chromium测试记为旧版退出失败。
- 快捷键空绑定残留 `N/A` 已在源码改为“未设置”，待重新构建与界面验证。键盘物理键名保留。

- 手柄死区：实际界面选0.3后保存为0，证据 `gamepad-before.json`；已将整数解析改为小数解析。面板重开同步已保存的全部手柄值，并说明手柄选项即时保存、底部按钮仅作用于键盘快捷键。关闭窗口清理未保存快捷键及捕获状态。全量构建 `mvdwp9mk` 已部署并核对12个产物哈希；死区0.3、灵敏度66、交换摇杆的保存与重开一致已通过，见 `gamepad-after.json`。测试后恢复死区0.1、灵敏度25及不交换摇杆。新增快捷键3项、标准全屏接口2项自动化测试通过；真实手柄运动、施法及目标选择尚未验证。

- 聊天过滤：22个开关均通过实际聊天组件显示检查，关闭隐藏对应类别消息、开启显示；仅调用客户端本地消息入口，没有向其他玩家发送消息。证据 `chat-filters.json`。
- 自定义快捷键：将背包临时改为 Ctrl+Shift+F8，实际打开当前版本的 `InventoryV3`，重开设置保留绑定，验后恢复 Alt+E；见 `shortcuts-action.json`。清空绑定当下显示空白的问题已补为“未设置”，同步翻译快捷键工具提示的 `None`。新增清空／取消测试通过；连同现有手柄测试，本轮10项通过，新增文案待新版实测。

- 手机／平板模拟：两端均正常登录当前构建 `mvdwp9mk`。50%渲染比例分别使画布844→422、1180→590；空数值不保存，锐化0实际传入GPU为0，未实现的亚像素入口不存在。音乐和音效25%实际增益均为0.25，音乐关闭暂停、开启恢复；见 `mobile-core-9361.json`、`mobile-core-9363.json`。
- 饱和度默认值0.15不符合原控件步长0.1，手机浏览器会判为无效，桌面滑块也无法准确表示。已将两端步长统一为0.05，保持默认效果；待新构建复核。

- 手机横屏公共输入编辑器：通过真实点击打开编辑器、填入75并点完成，渲染比例变为75%、画布844→633，随后同样操作恢复100%；见 `mobile-native-editor.json`。

- 六项桌面后处理（泛光、景深、自适应锐化、抗锯齿、卡通、饱和度）已逐项启停：真实渲染程序收到相应参数，关闭后对应着色器不再参与绘制；截图人工目视检查无黑屏或异常。景深范围／强度、卡通强度／边缘、自适应锐化对比／锐度均核对GPU值；见 `effects-uniforms.json` 与 `effect-*.png`。
- 桌面抗锯齿阈值的0.03步长也无法表示默认0.125，已统一移动端的0.001步长，防止控件值与真实设置不一致；待新构建复核。
- 手机／平板聊天行数2→8时预览高度实际增加，分类标签开关立即显示／隐藏；通知设1秒后分别约1.29／1.30秒消失（包含测试读取延迟），像素过滤变更出现刷新提示。验后恢复默认值；见 `interface-9361.json`、`interface-9363.json`。

- 帧率上限：真实渲染监听在约1.2秒内记录30档35帧、60档60帧、不限制72帧；帧率显示数值正常更新（样本58.1），验后恢复60且关闭计数器；见 `fps.json`。性能开销会令实际帧率低于上限，不将上限解释为保证帧率。
- 性能模式与显示范围：开启后实际后处理视口由1024×768降为768×576；范围4仅绘制4格内实体，范围20恢复6.08与17.69格处实体，保持真实实体位置未变。显示范围在性能模式关闭时不参与剔除，属于依赖条件；见 `performance.json`。

- 启动页保存图形比例后，实际偏好及存储中的值均为字符串“75”（`intro-before.json`）；游戏内通用设置要求数值，会使后续整组保存校验失败。已改为数值保存，并统一启动页“渲染比例／显示游戏光标”文案；待回归。
