**唯一视觉基准为本次实际生成并已放入根 README 的五张图片**，正式文件位于 `docs/assets/readme/`。不沿用旧版 2400 × 1680、图片内标题、旧设备尺寸或 Pillow 制作参数。

## 模板与输入管理

截图使用 Playwright 控制 Chromium，本机真实页面截图，再通过 HTML/CSS 合成和浏览器截图导出。实际使用的合成模板已保存到本目录；预览页沿用本次样式，将图片引用改为仓库正式素材。

截图辅助脚本按当次浏览器会话保存在 `work/`，尚无统一的一键截图 CLI。本目录记录可复用参数和操作，不把设计中的 CLI 描述为现成工具。模板不需要 AI 生成图片，正式参数不依赖临时目录里的旧脚本。

原始截图和预览仍属于生成物，放在 `work/` 或 `artifacts/`。模板、参数与流程保存在本目录并纳入版本管理；正式成图放在 `docs/assets/readme/`。截图使用浏览器视口模拟，不代表手机或平板真机验收。

后续请求示例：

> 按 docs/development/readme-images/README.md 更新 README 图片，以当前五张正式成图为基准。首图换成指定地图和角色，只重拍受影响的画面，沿用已保存的合成模板，先生成预览。

## 局部重拍

只重拍成图中明确可见且发生变化的画面；被设备框遮挡或已裁掉的区域变化不触发重拍。设备边框、布局变化仅重新合成；某一端 UI 变化仅重拍该端；图鉴、战斗或后台变化仅更新对应图。

保持截图角色、地图坐标、视口、镜头、裁剪和展示内容一致，不编辑 DOM 伪造状态，不为凑图改职业、资产或服务器倍率。同账号顺序登录，凭据留在未跟踪的本地配置。先生成预览，再替换正式图并同步文档站 `sources.json` 来源与哈希。未变化图片核对哈希保持不变。

当前没有统一截图 CLI；使用保存的参数、HTML 模板和实际 Playwright 会话。缺原图或资源加载失败时先补齐输入，不复用来源不明的图片。
