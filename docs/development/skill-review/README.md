## 统计口径

- 全量规划为 **12 条主职业线**，覆盖一转、二转、进阶二转、三转、四转及继承技能；诗人／舞娘合并为一条线。扩展职业不在这 12 条内。
- 已完成这 12 条线的代码复查与定向回归。代码复查不等同于逐技能实机验收。
- 后续实机批次按用户确认，只处理其中 **9 条线的 607 个独立技能**。各线合计 666 个条目，共享的一转技能和通用技能在总数中去重；607 不是全部 12 条线的总技能数。
- 最终为 **606 项有已接受处理记录，1 项按用户要求跳过，本批技能处理清单已收口**。处理覆盖率为 99.84%，不是功能通过率。
- 原 573 项实机记录按用户确认保留，包含失败、局部验证和待修问题。其后 34 项重新实机补测，33 项取得新的效果证据，1 项停止耗时随机采样。仅出现于技能树、学习前置或源码中，不算实机处理。
- 清单收口不表示所有问题已修复，也不表示全部分支、数值、动画、声音及官方一致性通过。技能处理数量、修复条目数量和未解决事项数量是三种不同统计，不能互相抵扣。
