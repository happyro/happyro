- 客户端 17 份分区表合并为 `NpcNameTranslations.zh-CN.json`；完整名称和有歧义的封包截断名称分别处理，不用同一截断前缀猜测不同人物身份。

## 并发与集成方式

采用一个集成人和最多三个并发专项：各代理独占不重叠脚本，共享词表、任务 JSON、地图来源及生成目录由集成人集中写入。已完成专项接续剩余审查和独立验证，不让多个代理同时写共享文件。

并发中实际发现依斯鲁得别译冲突及普通／True 两份任务源替换覆盖不同，已集中裁决并复核。红火焰误报和部分武器候选误报经当前源码与物品 ID 核实后撤回，不为“修复数量”制造改动。

## 保留问题与验证边界

- **Almond J 附魔实例信息损失**：当前实现销毁装备后重建，可能丢失绑定、时效、随机词条等实例信息。没有落实原地无损附魔接口；提示不能代替无损实现，此项属于独立功能修复。
- **手推车券 6606 缺少客户端资源**：服务端存在 `P_Cart_C`，但当前合并 itemInfo、运行 LUB、源包旧文本表及内置 itemInfo 均无该 ID，客户端目录也没有相应条目。缺少可靠资源名及图像来源，未借用其他图标、捏造条目或删除原任务要求。证据为 `cart-source/index.json`。
- **身份与导航候选**：历史校对的相似名称、韩文静态导航及缺少身份依据的候选，不全部等于当前加载实体的翻译缺陷。生成目录一致性不证明每个静态导航记录均有已审定中文身份；没有依据的项保留，不把旧候选数量当作当前缺陷数量。
- **剧情来源含糊**：杜兰树果贸易泛称、部分船长经历及个别四转语句在上游同样不明确，未凭音译猜造事实。
- **资源存在不等于画面验收**：插图引用已核对，但未逐张确认旧教程图片里的 UI 与当前产品一致；未因路径不同重复补图。
- **游戏行为范围**：没有走完全部职业、性别、多人竞争、断线恢复、手机佣兵控制及奖励满包的实机组合。共享试炼控制器、旧任务规则等不在本轮重构范围。转生迷宫借助隔离环境移动抵达节点，不声称完整步行路线验收。

“完成”指本轮约定的源码审计、确定问题修复及上述验证，不代表所有人物身份均有官方定论、游戏没有其他缺陷或所有流程已完成实机验收。
