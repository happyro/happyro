## 修复

| 问题 | 处理 |
| --- | --- |
| 查看器直接请求逻辑地图文件，共用场景的地图无法打开 | `DB.loadMapAliases` 共用于在线游戏和查看器；查看器启动地图前等待索引加载并同步给资源线程 |

- 655 条静态门户：目标地图存在、落点在范围内且可通行，源触发区域存在可通行格。此项是静态检查，不等于逐条实走。
