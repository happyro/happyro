# 公会界面补充修复

[返回公会审查](README.md)

日期：2026-10-29。根据截图复核，补充处理对话标题、驱逐记录文案和仓库记录窗口。

## 对话标题与文案

- `te-third-job-blocked.png` 是修复前的缺陷截图。移动端传送 NPC（job 45）现显示“传送入口”，不展示内部路由名；普通 NPC 名称保留，去除脚本后缀并修剪空白。无名城堡拉杆或缺少实体显示信息时显示“对话”。桌面 NPC 框没有同类自动实体标题。
- `desktop-4.png` 的 `management audit` 来自测试填写的驱逐原因，不是界面固定文案。保留玩家自定义内容原样显示，补测使用中文原因“公会功能验收”。
- 公会倾向图固定英文缩写改为正／邪／俗／誉并添加完整中文提示；解散失败的兜底提示改为中文。

## 仓库记录窗口（首轮）

- 桌面复用 `DesktopLightTheme.css`、`DesktopWindowHeader.css` 的浅色主题、标题栏、关闭按钮和滚动条；正文为 12px，记录以物品／成员操作／时间三列紧凑排列。
- 桌面默认窗口 760×540px；平板 640×600px，手机 430px 视口内为 398×600px。均受视口边界限制。
- 手机和平板继续使用移动端暗色布局。内部容器占满可用宽高，避免被内容固有宽度压成窄列；窗口置于 HUD 上方，操作栏不被遮挡。

## 横竖屏与公共样式补充

移动端仓库记录现复用 `MenuLayout` 的设备分类、字号和安全区，以及 `MenuTheme`、`MenuPaneLayout`、`MenuButtonSizing` 的滚动边距与分页尺寸。手机竖屏记录分行展示，手机横屏和平板横竖屏采用三列。平板窗口与菜单一致，最大 1040×640px，受视口及安全区约束。

移动端去掉记录内框，由内容区保留固定留白（手机 8px、平板 16px）；标题和分页底栏保持固定。记录数量显示在标题右侧“（最近 X 条）”，空状态与“加载失败”提示位于内容区，分页组件水平居中。旋转仅更新布局，不重置当前页。桌面继续复用冒险工具的公共标题栏：关闭按钮普通状态边框透明，悬停显示反馈，键盘焦点保留可见提示；打开窗口时聚焦对话框，避免关闭按钮一直显示焦点边框。

验证采用实际组件源码和 CSS、41 条测试记录及模拟 GUI 生命周期，在 Chromium 检查以下五种视口；这轮未重新执行服务器存取流程，也不作为实体手机或 iPad 测试。五种视口均检查了旋转、分页、空状态、错误状态和关闭操作，滚动前后底栏位置一致。相关 5 个测试文件 55 项测试通过，客户端完整构建通过，本次版式调整后仓库记录 4 项测试与五种视口检查通过，3338 入口已核验构建 `mvt16zsp`。
