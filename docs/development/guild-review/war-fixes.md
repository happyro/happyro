# 公会战客户端修复验证

## SE 守护石修复的红色提示

原生守护石修复流程随机发送 `EF_BEGINSPELL4`、`EF_BEGINSPELL2`、`EF_VOLCANO`（225）提示。实机 NPC 对话收到 225 时，客户端 `EffectTable.js` 原先只有注释，没有对应效果定义，因此玩家无法观察这一提示。

已补充有限时长的红色柱环，复用现有 `ring_red` 纹理和施法音效，跟随收到通知的实体，持续 1200 毫秒。没有更改服务端小游戏规则或答案。

- 单元验证：`npx vitest run tests/renderer/GuardianStoneCue.test.js`，1 项通过。
- 本机完整构建：`mvt9uw1q`。
- 实机验证：服务器对普通角色发送原生 `EF_VOLCANO` 通知，经过实际网络包和效果渲染器，在第一个绘制帧捕获到可见红光。
- [红光截图](evidence/war-fixes/volcano-red-cue.png)与[绘制时序](evidence/war-fixes/volcano-render-timing.json)。截图来自游戏画布，不包含 HTML 界面。

这是受控的同效果通知回放，不冒充在新构建下完成整轮守护石修复。原生 NPC 确实发送 225 的对话证据在 SE 修复流程记录中；此验证补足客户端对应通知能够显示的证据。

本次无头浏览器约每 400 毫秒绘制一帧，普通页面截图返回时效果可能已经结束。最终证据在实际绘制后立即读取游戏画布，没有延长效果、修改颜色或合成图像。首次捕获距效果起始 419 毫秒，透明度为 0.7。
