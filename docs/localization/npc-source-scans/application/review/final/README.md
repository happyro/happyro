## 新证据与边界

此前保留项中，12 项缺少客户端形象证据，4 项同坐标有多个 NPC。此次按服务端 `src/map/npc.hpp` 的 e_job_types 声明解析形象 ID，并把原枚举和 16 条 static_assert 交给 C++ 编译器核验。

每项均有单个 DVG 来源、精确地图坐标、相同服务端形象编号，且该位置只有一个实例满足该编号。隐藏触发器与可见角色分开处理；例如 HIDDEN_WARP_NPC 为 139，与席鲁德的 1_M_04（50）不同，苏阿德为 10378，与神官的 4_F_TRAINEE（920）不同。保留原内部名及 # 后缀，未改变脚本条件、商品、费用、坐标或形象。

顺带复核先前形象证据：约兰达、叛乱军队员和荆棘藤刺三项的目录形象来自同坐标客户端导航，原脚本使用隐藏占位形象，不应称为原声明形象一致。其独占位置和对应导航资料仍支持原匹配，本轮保留名称，记录证据来源区别。未修改客户端缺少素材的形象常量映射。

同步 70 处新改名对象的精确自身对话标题。简称、其他说话者及普通剧情正文不全局替换，逐条见 [titles.json](titles.json)。

## 导航遗漏修复

同位置有隐藏触发器时，原生成器按第一条记录选名，席鲁德仍被隐藏触发器的旧名覆盖。现在优先选可交互 NPC，再选有显示形象的 NPC，同优先级保留原顺序。新增回归覆盖隐藏触发器的前后顺序和不同坐标独立选择；全目录验证保证输出名称确实属于该位置合适的 NPC。
