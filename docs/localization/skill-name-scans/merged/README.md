## 合并规则

按技能 ID 对齐，同时校验内部名。默认采用小册子国服中文名称；小册子内部名不符或没有可用中文时，采用 RO321 复兴版中文名称。复兴前、台版和字母索引不作为替代版本。仅去除首尾空白，不自行翻译或拼接新名称。

11 个冲突条目选择 RO321，以处理明确用字问题、简化标题、区分技能变体或统一公会称谓；逐项理由见 [决策表](decisions.md) 与 rules.json。ID 318 小册子内部名缺少末尾 R，采用与项目身份一致的 RO321“冷笑话”。“钢铁之心／霸体”按默认规则选择“霸体”。

147 项原始名称冲突、1 项内部名差异和 2 项空白差异已逐项给出最终选择，无待裁决冲突；这不代表所有条目都有可靠外部中文来源。项目现名保留项及全部候选可在 JSON 中检索。
