# 技能引用二次审查

本轮发现并修复了名称主表以外的遗漏，名称决策本身没有变更。结构化范围与依据见 [second-review.json](second-review.json)。

## 修正内容

- 技能正文及状态：补齐跆拳准备姿态、月亮／星星光辉、鲜虾、攻击准备等短名称；区分技能引用与普通动作描述。
- 前置技能：生成器中 17 条手写覆盖条件改为通过内部名读取共享名称，避免主表更新后继续输出旧名；原先“电气注入”按运行时前置 ID 2341 修正为“全气注入”，未改变等级条件。
- 界面：桌面和移动端材料窗口的“素材变化”“元素分析”读取同一名称表；排行榜说明同步“太拳任务”。
- 物品：补回此前误排的 28 条技能引用，再按物品脚本中的技能 key 审查短名称和同名技能。例如乐师装备脚本使用 WM_REVERBERATION，应显示“残响”，不能因正文写了“振动回响”就当作 WL_REVERBERATION 保留。
- NPC：补齐学院、转职考题、职业教学、卡普拉、公会和租赁对话，包括未出现在最初名称比较表中的“敏捷提升”“祝福”等旧别名。学院脚本含非 UTF-8 字节，修改按原字节保留文件其他部分，未因解码失败漏扫。

## 明确说明错误

1. 人工生命教学把创建消耗与制作材料混在一起。现区分新建消耗 1 个艾普理欧、安息召回消耗 1 个生命的种子；保留 Vaporize、Embryo、Homunculus Resurrection 英文答案及任务判定。
2. 塔诺斯大刀-AD（600016）写有精炼 +9 自动发动技能，但当前服务端装备脚本只有 ATK +5%，没有此自动施法分支。删除错误效果说明。
3. 普隆德拉教学声称治疗术几乎能解除所有异常，改为沉默、黑暗、混乱等特定异常，并统一“治疗术／治愈术／天使之赐福”的名称。

## 保留范围

不对普通词全局替换。例如枪手“发动三连击”不改成武僧“六合拳”，“霰弹枪”不改成技能“弹片四射”，制作材料“风属性转换器”不改成元素转换技能。物品 1268 的背景叙述恢复“致命伤”，实际技能效果行仍使用“致命伤口”。

本轮是名称引用与明确错误复查，不是全部技能机制的逐句重译；保留项目现名的 198 项及无可确认名称的 2549 不作自译。复兴前脚本、原始输入快照和历史记录不回写。
