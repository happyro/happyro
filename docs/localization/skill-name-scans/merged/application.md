## 描述纠错依据

- 243 AM_CALLHOMUN：服务端 `src/map/skill.cpp` 的 Renewal 分支区分新建与安息召回；新建消耗艾普理欧（7142），安息召回消耗生命的种子（7140）。说明按这两个分支修正。
- 2268 NC_SHAPESHIFT：服务端 `db/re/skill_db.yml` 各等级消耗相应属性石 3 个、燃料 2 个；总述原先“1 个属性石”修正为“3 个”。

只修文字，未改变技能 ID、伤害、消耗、施放条件或任务逻辑。

## 保留与审查边界

普通词不能按技能名全局替换。例如“等级提升”“恢复”“精神训练”、冰洞任务的解除魔法、普通圣光意象，以及物品“元素转换器”“大地之力”保留上下文含义。任务 8193 的“双重扫射”是弓箭手技能的比喻引用，随技能统一为“二连矢”。

`SkillInfo.js` 为已校验的静态输入快照，旧名保留在源快照；运行使用生成技能表与名称覆盖。`StatusInfo.js` 中被中文状态覆盖层替代的原始文字不作无意义改写。没有对全部 NPC 普通叙述、所有短词和网站整段说明作自动替换，也不宣称所有描述均逐句审核完毕。
