# RO321 技能名称扫描

采集职业技能目录的 88 个职业入口和 26 个字母索引，并补查字母索引中未被职业页覆盖的 319 个 ID，共 433 个内容页面。得到 1444 个有分版本名称的技能、3391 条去重版本名称记录。

版本分别保留 pre（复兴前）、re（复兴/新版）、iro（站点标签为台版）。每个版本覆盖的唯一 ID：{"pre": 752, "re": 1442, "iro": 1197}。没有对应版本时不回退使用其他版本。

字母目录覆盖 1227 个 ID；职业页还发现 217 个字母目录未列出的 ID。已发现入口全部处理，不声称覆盖网站未被任何目录链接的隐藏页面。
