## 合并规则

- 两站独立保存原文、技能 ID、内部名、版本及来源；不把网站同名自动判为正确。
- RO321 对照只使用复兴/新版，复兴前和站点所称台版单独保留。
- 暂不套用网站技能说明、伤害、消耗和效果；用户已确认：此前按物品 ID 核实的名称引用同步和明确说明纠错可以保留，无需回滚；不整段重译描述、不修改数值或效果。已按用户授权同步游戏名称及明确技能引用，并按服务端证据纠正两处描述。
- 用户已授权决定冲突：优先小册子国服中文，身份或中文不合格时采用 RO321 复兴版；11 项明确例外逐项记录理由。最终名称与选择依据见[合并结果](merged/README.md)。
- 1,767 个项目 ID 中，采用小册子 1,555 项、RO321 13 项，保留项目现名 198 项，1 项因无来源且无现名而明确留空。共有 1,059 项名称变化或补充，已应用到项目；本机服务端已重载，API 资料已重新导入，见[本机更新记录](merged/local-update.md)。

## 验证与追溯

小册子全部 79 页使用独立 HTML 表格解析器逐字段复核。RO321 的全部内容页面使用另一套 HTML 解析器核对版本与名称，并检查同一 ID 的内部名是否矛盾。索引发现 ID 的补查队列全部处理；分片条数、唯一 ID 和 SHA-256 全部核验。原始 HTML、扫描断点及本轮脚本位于 work/skill-name-sources/，页面哈希和正式分片位于本目录；验证摘要见 verification.json。
