## 数据和证据

各快照 `manifest.json` 提供原始汇总文件 SHA-256、记录数及分片范围和哈希；`data/` 每文件最多 1,000 个 ID。读取全部 data 分片并按 ID 合并即可重建名称对象。

`evidence/` 每文件最多保存 100 页提取记录，包含来源 URL、响应 SHA-256 和该页物品；`evidence/index.json` 是证据文件清单。RO321 另保存 61 份补充详情缓存。原始 HTML 不复制到 docs；小册子 grid 的压缩 HTML 位于 `work/item-name-sources/dvg-grid/pages/`。
