## 合并规则

按 ID 对齐，名称必须为可确认中文，且 Aegis 与项目一致（忽略大小写）。小册子列表优先，其次小册子网格，最后 RO321。网格没有 Aegis，只在另一来源能确认同 ID 身份时采用，并独立记录证明来源，绝不伪造网格字段。

仅移除标题末尾的插槽数。空名称、日韩未译名、占位名、身份冲突不覆盖项目名称；纯汉字但语言未经确认的 33 个网格候选精确列入排除表。没有来源的条目保留现名，不自行翻译。名称差异的取舍是明确的来源优先规则，并不宣称某网站所有翻译都绝对正确。

## 同步范围和结果

较本轮提交基线新增 235 个可靠映射；服务端实际改名 232 个，客户端改名 178 个。现有映射条目的名称未因合并规则改变。

- 服务端：Renewal 物品库、import 名称检查、NPC 显式物品链接检查和 23 项奖励菜单标签；游戏数值、内部标识及菜单控制逻辑不变。
- 客户端：ItemInfo 的名称、已鉴定及未鉴定说明中的 14 项审查引用；通用未鉴定名称不变。卡片前缀、道具服务、任务链接均执行映射一致性检查。
- API／Admin／冒险工具：共用物品、说明、附魔和 NPC 目录更新；图片映射与英文名称不变。Admin 不另维护独立物品翻译表。
- 运行资源：11 个 Lua 目标通过编译及逐值语义回环，变更的 ItemInfo 备份后安装；目标哈希与清单核对。安装证据位于 `work/item-name-merge/runtime-install.json`。

## 残留审查边界

按本轮实际改名的 232 个旧名称扫描七仓库受版本管理文本及本地化输入，排除源快照、映射证据和历史 changelog。剩余文本按身份保留：技能“海洋之力”“升龙”、普通叙述中的钓鱼竿／小缎带／夏日凉鞋、任务中的升龙汤及旧囚服、普通属性弓（1730–1733）与改良版（18137–18140）不同 ID、腮红任务实际发放 5040 而非改名的 18607、其他未映射型号和 Pre-Renewal 数据。不得按字符串全局替换这些内容。

扫描不把“无可靠来源”的 13,388 个条目伪装为已翻译；后续取得可靠资料后才补充映射。本轮完成的是现有扫描证据支持的合并和一致性同步，不代表所有物品都有中文来源。没有进行实机玩法验收。
