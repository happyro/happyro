# 第四轮：按实际技能材料反查

从 Renewal skill_db.yml 的 Requires.ItemCost 出发，通过 AegisName 对应物品 ID 与已审核名称，检查完整技能说明（含各等级），避免仅搜索旧名称而漏掉其他别名。

发现 145 个去重候选技能／物品组合，新增修正 127 处定点引用，涉及 116 个技能。包括机甲燃料、化妆材料、忍者用石、元素碎片、元素卷轴、润喉糖、四转酸液／植物瓶／能量石／灵符等。材料名全部读取两站已审核映射。

精灵召唤 2457—2460 的低等级材料是 990—993，高等级材料是 994—997，分别按实际 ID 修正，避免矿石与原石对调。技能 2268 的绯红点数／柠檬绿点数对应 6360／6363，也已统一。技能 243 创建人工生命使用第一项材料 7142；名称修正为艾普理欧，不根据通称自行翻译。

## 保留边界

- 288／483 中魔力矿石的共享后缀省略语义正确。
- 231 的额外 ItemCost 行不等于当前五个等级均可使用，保留现有等级说明。
- 发现两项玩法说明差异，单独记录，未混入名称修复：243 在 Renewal 下从安息召回还会消耗第二项材料 7140（生命的种子），现有说明未提及；2268 总述写 1 个属性石而分级写 3 个，数量说明不一致。另有前轮记录的配方 1463 数量差异。本次不修改服务端规则或说明数量。
