# 魔物名称与信息合并

共 2685 个来源／项目 ID，767 个项目 ID 的候选名称与现名不同。候选仅供后续应用审查；本轮不修改产品数据。

名称按 ID 和内部名匹配，内部名冲突不自动选择。身份吻合时优先小册子国服中文，其次 RO321 复兴中文；没有可靠中文保持候选为空并保留现名，不自行翻译。该默认规则逐条写入 reason。两站冲突与身份问题见 [冲突表](conflicts.md)。needsReview 标记冲突或无中文候选；reviewFlags 提示可能的截断／前缀差异，不能据此自动认定错字或删除变体信息。

相关信息按来源并排合并到 information，不覆盖彼此；fieldDifferences 比较明确同义字段，体型只为比较规范化。`—` 保留原文，不擅自解释为 0。掉落、地图、技能链接及来源标签保留，网站计算攻击力不等同于项目 Attack/Attack2。
