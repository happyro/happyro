# 魔物名称二次遗漏复查

本轮发现并修复三类遗漏，继续沿用已有来源支持的名称，没有新增自行翻译：

- 佣兵 2325（M_BAPHOMET_）仍在 mercenary_db.yml 显示 Baphomet，现与同 ID 魔物资料统一为小巴风特。此前只同步了两种教皇佣兵；检查现已扩展到全部已改名魔物与佣兵 ID 的交集。
- 欺瞒的别墅使用 21317／21361 两个形态，靠近吊灯的战斗提示仍写“扭曲之神芙蕾雅”，现统一为已审定的“扭曲之神”。
- 全部 49 个可解析且对应项目魔物的 NAVI 标签中有 40 个名称不一致，涉及 34 个魔物。例如 FREEZER 被标成冰巨人，GEOGRAPHER 被标成地理学家；现按内部名对应水灵龟、邪恶向日葵等已有来源支持的项目名称。另同步同一任务的 7 处摘要。

## 审查范围与保留项

重新检索 88 个已修正魔物的旧名及内部名，覆盖 Renewal 数据库、启用及可用脚本、客户端 DB 和 kRO 翻译源；核对 quest_db 的明确目标与两份任务表，未发现这些已改名 ID 对应任务残留原名称。检查客户端名称查询、游戏头顶／战斗显示、鉴定考试、魔物信息窗口及导航查询路径。

同名不同 ID 不直接改写。例如阿卡布、埃奇欧、冰巨人、迦利、土狼、火蜥蜴、火鸟等名称仍对应各自其他 ID；与本轮修正的变体不能混为一谈。舒朗的剧情 NPC 称呼与“复活的舒朗”等专用刷怪名称保留。神殿守卫的剧情角色／职位称呼也不按魔物外观 ID 一律改名。技能名称、独立物品专名不随召唤魔物名称改变。鉴定考试使用原始服务端任务标签是有意行为。

当前 21311 的完整名称“不稳定的神殿护卫”超过封包容量，服务端保留原短标签，由客户端按当前 ID 和精确短标签还原；这不是漏改。不能确认的地区别名保持原样。
