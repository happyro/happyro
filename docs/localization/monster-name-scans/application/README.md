# 魔物名称应用审查

已按 ID 和内部名审查项目的 2,675 个魔物；修正 96 个名称，补齐客户端原先遗漏的 110 个已有项目名称，并同步服务端、API、冒险工具与游戏内显示。逐项依据见[修正清单](changes.md)和[全部决策](decisions.json)。应用前的两站扫描与合并快照保持原样。

## 名称取舍

- 不把 767 条合并候选直接全量覆盖。已有来源支持的地区别名保留；并列别名不直接拼成一个名称，数据库后缀不作为自然显示名。
- 保留角色、颜色、武器类型与任务变体等辨识信息；来源仅给出更短名称，不足以认定现有附加信息错误。不能确认的名称保持原样。
- 第三方共核对 574 个 Divine Pride 页面，逐页核验 ID／内部名并保存原文、URL 和 HTML SHA-256。使用其 cRO／twRO 名称作补充证据；繁体名称只经 ICU Traditional-Simplified 字形转换，没有自行翻译。见[第三方记录](third-party.json)。
- 1202 PHENDARK 原本被客户端显示为“兽人腐尸”，与服务端及第三方身份不符，现为“阿修罗狂战士”。小巴风特的召唤变体 2325 另有同 ID 中文及精灵证据，不能与大巴风特混用。
