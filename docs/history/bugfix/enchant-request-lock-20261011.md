# 附魔提交与结果锁定修复（2026-10-11）

本次检查现有附魔功能，不补装备说明或图片，不改变服务端费用、成功率或支持装备名单。

## 根因与修复

桌面 `Enchant.js` 发出请求后只禁止关闭窗口，装备和方式仍可改变、提交按钮仍可再次触发。服务端在第一次附魔结果后结束会话，第二次请求被忽略，但客户端待处理记录已经被覆盖，可能把第一件装备的结果显示到第二件装备。

另一个问题是材料、Zeny 或装备状态变化后，提交按钮仍沿用旧的可用状态。服务端会静默拒绝无效请求，不发附魔结果；旧客户端已进入等待锁定，无法正常关闭窗口。

修复为等待期间锁定全部附魔操作，并在提交前重新查询当前装备和费用条件；结果返回并关闭窗口后解除控件锁定，允许重新打开。补齐这一流程的中文状态提示。

附魔目录同步检查发现源文件校验值及一项名称落后于当前服务端，重新生成 `ItemServices.json` 后一致性检查通过。138 个附魔组和改造配方保持相同，仅同步塔纳托斯之弓名称和来源哈希。
