# 地图显示名称与搜索

地图代码决定身份，当前显示名负责界面表达；地图搜索同时支持当前显示名和地图代码；来源全称和历史别名只保留供审计，不参与地图关键词搜索。不能把外站完整标题直接覆盖所有界面。

## 搜索规则

冒险工具与地图导航只匹配当前显示名称，使用不区分大小写的连续包含匹配。排序为显示名称精确匹配、前缀匹配、包含匹配，筛选排序后分页。旧全称、历史别名以及与显示名称不同的地图代码都不参与关键词匹配；后台独立的地图代码筛选仍按代码工作。

例如“艾尔帕兰”可以找到“艾尔帕兰”和“艾尔帕兰 露依纳”，不会仅因城堡的历史别名带有“艾尔帕兰”而返回名称中没有这些字的城堡。“南门”仍能匹配“普隆德拉南门”；“首都普隆德拉”不再匹配当前名称“普隆德拉”。

## 玩家地图可见性

资源支持与玩家列表可见性分别管理。[player-visibility.json](../../localization/maps/player-visibility.json) 明确记录隐藏原因，生成到共享目录的 `player_hidden` 字段；API 的玩家地图查询与客户端导航使用相同标记，搜索、当前地图置顶及分页均不绕过此规则。后台全量地图和底层资源仍保留。

`new_event` 和 `pprontera` 没有本项目 NPC 或脚本入口，从玩家列表排除。后者有旧版普隆德拉资源的社区来源证据，不视为当前正常城市。此规则不推广为“无 NPC 一律隐藏”，避免误伤正常原野。

公会区域 `alde_gld` 显示为“艾尔帕兰 露依纳”，保留所属城市；外站全称不参与搜索。简称规则同时适用于公会区域，不限于城镇标记。
