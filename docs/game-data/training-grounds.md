# 训练场

普隆德拉 `(246,62)` 的训练教官提供三个入口：基础训练场 `tra_fild01`、1/10 训练场 `tra_fild02`、1/100 训练场 `tra_fild03`。三场都使用已补充的官方地图，角色可正常退出并重新登录。

## 场内服务

- 管理员可传送至中央、3 点、9 点和 6 点区域，或返回普隆德拉。各区域隐藏当前所在区域的选项。
- 左右两侧传送门可前往其他训练场或普隆德拉；取消后可正常走开并再次使用。
- 个人仓库每次收费 1000 Zeny，需要初心者基本技能至少 6 级；打开仓库前关闭 NPC 对话，避免窗口重叠。
- 公会仓库每次成功打开收费 1000 Zeny，需要公会仓库技能与成员仓库权限。非成员、权限不足、金币不足或仓库正被占用时不扣费。
- 三场共 216 个固定假人，涉及 143 个魔物 ID，分为体型、种族、属性、物理抗性和魔法抗性训练对象。外观采用官方 `S_DUMMY_*` 资源，不以未知魔物外观代替。
