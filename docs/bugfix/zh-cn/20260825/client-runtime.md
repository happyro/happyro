# 客户端运行时修复

## 运行时数据表

- 称号乱码/韩文：`localization/client/data/titletable.json` 覆盖 1000-1046，并在标题表加载后合并。
- 技能描述韩文：`SkillDescriptionLocalization.js` 识别韩文描述；`NV_BASIC`、`NV_FIRSTAID`、`NV_TRICKDEAD` 使用中文说明，其他未收录项显示中文机械信息摘要。
- 技能描述加载：原实现只覆盖旧客户端分支，且未明确 UTF-8；现在当前 PACKETVER 路径同样加载，并显式按 UTF-8 读取 loose-data 表。
- 消息表：自动喂食、生命体喂食、画面震动、光晕和视野缩放的 `On/Off` 改为“开启/关闭”。

## 静态表与界面

- 地图：修复世界地图暴露的英文或乱码名称，同时保留地图键和资源路径。
- 职业：初心者、超级初心者、进阶初心者、顶级初心者改为中文。
- 导航：筛选项改为“全部 / NPC / 魔物”，地图标题使用中文地图信息。
- 对话：修复返回选项以及确认/取消按钮中的韩文。
- 背包：修复标签/选项空白和本地化文案。
- ESC、任务、队伍、NPC、弹窗：同步中文文本并补足中文文本所需布局。
- 签到：空状态改为“当前没有进行中的签到活动”。

## 邮件

邮件异常不是服务端数据库问题。`Rodex.js` 在 detached host 场景读取了错误 DOM 容器；修复挂载和清理对象后，邮件窗口恢复正常生命周期。

## 源头归属

能由翻译回写生成的文件必须同步对应 agent 分块。加载顺序、编码检测、DOM 生命周期、CSS 和缺失资源降级属于客户端源码修复，即使现象表现为乱码或韩文，也不能只改译文文件。
