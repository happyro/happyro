# 魔物悬停名称本地化

## 现象

鼠标移动到魔物时，名称显示服务端返回的英文，例如 `Poring`，而不是已有的中文名称“波利”。

## 来源与修复

- `EntityControl.onMouseOver()` 在悬停时向服务端发送名称请求。
- 服务端名称在 `Entity.js` 的 `onEntityIdentity()` 中通过 `pkt.CName` 返回。
- 如果客户端直接使用 `pkt.CName`，就会绕过 `MonsterNameTable.js` 中已有的中文名称表。
- 对普通魔物以及被识别为魔物的 NPC，应使用实体职业/魔物 ID 查询 `DB.getMonsterName()`；名称表没有覆盖的 ID 才回退到 `pkt.CName`。
- 本例的魔物 ID `1002` 在 `MonsterNameTable.js` 中对应“波利”。

## 术语修正

`Fabre` 是英文正式名称，但在中文客户端中应显示为“绿毛虫”，而不是音译“法布雷”。相关基础和变体 ID 已统一为“绿毛虫”“坚硬绿毛虫”“绿毛虫首领”和“草地绿毛虫”。后续检查魔物名称时，应优先遵循中文术语表，避免同一魔物在不同翻译源中出现音译和意译混用。

## 构建判断

这类修复属于客户端名称显示逻辑，不需要修改服务端 NPC 文本，也不需要重建 `.lub`。修改后重新构建 PWA 即可。
