# P0/P1 常用野外 NPC 名称

## 状态

P0 普隆德拉周边和 P1 吉芬、梦罗克、斐扬周边的活动 NPC 清单、客户端显式映射、封包截断检查、测试、构建和代表性实机取样均已完成，四个批次已标记为“已实现”。

| 优先级 | 批次 | 地图范围 | 地图数 | 可见实例 | 唯一基础名称 |

四个批次合计 60 张地图、157 个玩家可见实例和 101 个全局去重基础名称。没有可见 NPC 的地图仍属于完成范围，其完成证据是活动脚本扫描结果为零，而不是从地图范围中删除。

## 清单与分类

- [`../p0-p1-field-inventory.csv`](../p0-p1-field-inventory.csv) 从 Renewal 活动入口 `npc/re/scripts_main.conf` 递归展开 850 个活动脚本文件。
- 原始定义共 253 条，只纳入 `script`、`shop`、`cashshop` 和 `duplicate` 类型。
- 人工规则排除 96 条：75 条空显示名、17 条隐藏或触发实体、4 条内部控制实体。
- 清单逐实例保留地图、坐标、完整内部名称、基础名称、译文、定义类型和服务端源文件行号。
- `#...` 实例后缀与 `::...` 事件别名只用于内部寻址，不进入基础名称；运行时仍原样保留。

## 翻译来源

- 任务采集点沿用 Renewal 物品库现有译名，例如“杰勒比结晶”“黏糊的脚蹼”“兽人犬齿”和“蝗虫后腿”。
- 魔物型 NPC 沿用当前魔物名称表，例如“罗达蛙”。
- 剧情人物优先沿用已汉化脚本中的称呼，例如“罗丝卡”“哲虎”和“李大监”。
- 新增客户端 `P0P1FieldNpcNameTable.js`，显式登记 98 个 ASCII 基础名称；另有“刺客”“刺客大叔”“刺客守卫”3 个服务端名称原本已为中文。
- `Signpost`、`Mad Scientist` 和 `Suspicious Man` 使用适用于所有地图的通用译名，避免旧表把其他剧情人物或具体地点名称错误套用到野外实体。

## 自动验收

- 清单 157 个可见实例、101 个唯一基础名称，ASCII 显式映射缺失数为 0。
- 显式表 98 项，所有译值均包含中文字符。
- 四批代表名称、通用名称纠正、未知名称原样返回和全部超长名称截断映射由 `NpcNameTable.test.js` 检查。
- 客户端全量测试和 PWA 构建通过后，再进行代表性实机取样。

## 实机取样

每批选择一个实际可见 NPC，验证地图载入和悬停中文名称；另对斐扬样本执行点击寻路，确认名称处理不影响 NPC 点击定位。取样结果如下：

| 批次 | 地图 | 样本 | 结果 |
| --- | --- | --- | --- |
| 普隆德拉周边 | `prt_fild05` | 地下水道守卫 | 地图载入、悬停中文名称通过。 |
| 吉芬周边 | `gef_fild06` | 地图调查员杰菲尔 | 地图载入、悬停中文名称通过。 |
| 梦罗克周边 | `moc_fild11` | 会说话的狗 | 地图载入、悬停中文名称通过。 |
| 斐扬周边 | `pay_fild07` | 动物学家 | 地图载入、悬停中文名称和点击寻路通过。 |

实机只作代表性取样，全范围完整性由活动脚本清单和缺失数为 0 的自动检查保证。
