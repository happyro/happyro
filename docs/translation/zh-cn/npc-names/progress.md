# NPC 名称翻译进度

## 状态标准

| 状态 | 定义 |
| --- | --- |
| 未开始 | 尚未建立目标城镇的活动地图范围和全量名称清单。 |
| 部分覆盖 | 已翻译部分核心或公共 NPC，但没有证明全地图英文基础名称缺失数为 0。 |
| 待实机验收 | 全量清单与客户端映射的自动检查已通过，但尚未完成目标地图的实机抽查。 |
| 全地图已实现 | 范围、全量清单、客户端映射、封包截断、构建和实机验收全部通过。 |

“已实现”只用于完整城镇范围，不能根据少量核心 NPC、单个服务端脚本文件或服务端构建通过来判定。

## 统计口径

- 旧估算声明数包含重复实例、隐藏脚本和非玩家可见项，只保留为历史工作量参考，不能作为完成数量。
- 全量检查从服务端当前活动脚本的 NPC 定义中提取第三个制表符字段，再去除 `#...` 实例后缀和 `::...` 事件别名，以英文基础名称去重。
- 每个城镇必须先明确主地图和关联室内地图范围。周边野外、迷宫和地下城是否纳入，必须在该城镇批次文档中明确说明。
- `terms-names.csv` 是跨地图复用的术语表，不是全量完成清单；不能用术语表条目数证明整张地图已经完成。
- 客户端运行时名称表是悬停名称和名称牌译文的维护源。服务端脚本仍是名称清单和对话标题的来源，但不得为了悬停显示而批量修改可能被脚本引用的 NPC 内部标识。
