# 本地化来源与审查

| 目录 | 用途 |
| --- | --- |
| `items/` | 物品网站来源采集、身份交叉核对、名称映射及受控同步 |
| `monsters/` | 魔物来源采集、合并、应用与证据校验 |
| `npcs/` | NPC 来源采集、匹配、脚本名称审计与受控规范化 |
| `maps/` | 地图名称来源、显示名称及传送标签 |

运行资料和图片生成在 [resources](../resources/README.md)；Lua 编译在 [client](../client/README.md)。各入口无参数显示帮助，采集、生成、应用均须显式执行。不因扫描成功自动批准翻译，也不把网站来源与当前游戏 ID 的身份核对省略。

NPC 的 `audit.py`/`normalize.py` 与 `scan_sources.py`/`reconcile_names.py`/`apply_names.py` 在同一领域目录下，但保留不同职责：前者审查脚本显示名与内部标识，后者比对外部来源。不能把内部标识改写成翻译显示名。

来源解析器保留各网站和物品/地图/NPC/魔物的业务差异；不把不同身份判断规则强行合成通用爬虫。统一依赖和离线解析回归由 [tools/check.py](../check.py) 管理，测试不访问外部网站。
